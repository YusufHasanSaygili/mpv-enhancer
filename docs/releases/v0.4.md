# MPV Enhancer v0.4

This public pre-release completes the core per-item settings model and selected
item panel. It is an immutable fork point for contributors who want to extend
the typed settings foundation independently.

## Highlights

- Adds validated per-item speed, pan-and-scan, volume, mute, and subtitle
  visibility overrides without exposing raw mpv commands.
- Resolves deterministic baseline, application, playlist, and item layers while
  preserving inherited values.
- Supports Ctrl/Shift multi-edit with inherited, explicit, and mixed control
  states; changing one field preserves every unrelated override.
- Resets every managed mpv property and applies complete effective settings
  before each file, preventing settings from leaking into the next episode.
- Applies changes to the currently playing item live and stores them for future
  playback.
- Adds Default, 1.2× Playback, Fill Display, Subtitles On, and Subtitles Off
  presets with a generated preview of every typed patch.
- Shows compact queue badges such as `1.2×`, `Fill`, `Muted`, and `Subs Off`.

## Requirements and compatibility

- Windows 10 or Windows 11
- Python 3.12 for the development wheel
- PySide6 6.x from the locked runtime requirements asset
- A separate trusted mpv installation; mpv is detected but is not bundled

Install the locked runtime requirements and wheel in a fresh Python 3.12
virtual environment, then run `mpv-enhancer`. Existing v0.3 machine-local mpv
preferences remain compatible. Playlist persistence has not shipped, so no
playlist migration is required.

## Known limitations

- Settings exist only for the current in-memory queue; playlist save/open and
  session recovery are planned for a later slice.
- Subtitle and audio language preference, track selection, and timing controls
  are not included yet.
- Advanced crop, aspect, zoom, pan, rotation, deinterlace, and image controls
  are not included yet.
- The planned three-second transition experience is not included yet.
- Local files only; folders, remote URLs, and network streams are rejected.
- No standalone executable or installer; this release is a Python wheel plus a
  locked runtime requirements file.
- mpv is an external application and is not included in any release asset.
