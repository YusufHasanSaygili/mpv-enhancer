# MPV Enhancer v0.1

This public pre-release establishes the Windows application foundation and a
runnable English desktop shell. It is an immutable fork point for contributors
who want to extend the first slice independently.

## Highlights

- Opens a PySide6 desktop shell with settings, video/transport, and queue
  regions.
- Stores settings, caches, logs, and crash directories outside the repository.
- Discovers a selected mpv executable, an explicit development override, PATH,
  and standard Windows locations without invoking a command shell.
- Provides an English Preferences and diagnostics flow when mpv is unavailable.
- Includes required Windows CI and a reproducible local quality gate.

## Requirements and compatibility

- Windows 10 or Windows 11
- Python 3.12 for the development wheel
- PySide6 6.x, installed automatically with the wheel
- A separate mpv installation is detected for diagnostics but is not bundled

Install the development wheel in a fresh Python 3.12 virtual environment, then
run `mpv-enhancer`. When upgrading from an earlier development checkout, create
a fresh environment and install the new wheel. This release has no data-format
migration.

## Known limitations

- No media playback, queue editing, transport controls, or per-item settings.
- No standalone executable or installer; those are planned for a later
  packaging slice.
- The video and queue regions are intentional shell placeholders.
- mpv discovery and diagnostics are implemented, but mpv is not embedded yet.
