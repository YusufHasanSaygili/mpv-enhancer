# MPV Enhancer v0.1.1

This public pre-release is the verified recovery release for the v0.1
foundation slice. It preserves the same application behavior while correcting
the public checksum manifest used by the clean-Windows verification job.

The immutable v0.1 release remains available as the original fork point, but
its checksum manifest references an internal `.gitignore` file that was not
published. Use v0.1.1 for verified downloads and new forks.

## Highlights

- Opens a PySide6 desktop shell with settings, video/transport, and queue
  regions.
- Stores settings, caches, logs, and crash directories outside the repository.
- Discovers mpv safely and provides an English Preferences and diagnostics flow
  when mpv is unavailable.
- Includes required Windows CI and a reproducible local quality gate.
- Excludes unshipped hidden build metadata from release checksums and evidence.

## Requirements and compatibility

- Windows 10 or Windows 11
- Python 3.12 for the development wheel
- PySide6 6.x, installed from the locked runtime requirements asset
- A separate mpv installation is detected for diagnostics but is not bundled

Install the locked runtime requirements and development wheel in a fresh Python
3.12 virtual environment, then run `mpv-enhancer`. This release has no
data-format migration.

## Known limitations

- No media playback, queue editing, transport controls, or per-item settings.
- No standalone executable or installer; those are planned for a later
  packaging slice.
- The video and queue regions are intentional shell placeholders.
- mpv discovery and diagnostics are implemented, but mpv is not embedded yet.
