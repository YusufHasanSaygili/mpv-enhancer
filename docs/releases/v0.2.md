# MPV Enhancer v0.2

This public pre-release completes the queue, file-drop, reorder, selection, and
undo slice. It is an immutable fork point for contributors who want to extend
the queue foundation independently.

## Highlights

- Drops supported local media files from Windows Explorer while retaining every
  valid file from a mixed drop in its original order.
- Gives every queue entry a stable UUID, allowing duplicate paths with
  independent identity and metadata.
- Reorders items with a visible drag handle or `Alt+Up` and `Alt+Down` without
  changing their UUIDs or metadata.
- Supports non-adjacent Ctrl selection, Shift ranges, Ctrl+A, Delete, confirmed
  clearing, and exact Undo/Redo.
- Presents accessible queue instructions, selection summaries, title elision,
  current-item state, and an override-status placeholder.

## Requirements and compatibility

- Windows 10 or Windows 11
- Python 3.12 for the development wheel
- PySide6 6.x from the locked runtime requirements asset
- A separate mpv installation is detected for diagnostics but is not bundled

Install the locked runtime requirements and development wheel in a fresh Python
3.12 virtual environment, then run `mpv-enhancer`. This release has no persisted
playlist format and requires no data migration from v0.1.1.

## Known limitations

- No media playback, transport controls, playlist persistence, or per-item
  playback settings.
- Local files only; folders, remote URLs, and network streams are rejected.
- The override row displays `No overrides` until per-item settings are added.
- No standalone executable or installer; this release is a Python wheel plus a
  locked runtime requirements file.
- mpv discovery and diagnostics are implemented, but mpv is not embedded yet.
