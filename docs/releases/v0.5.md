# MPV Enhancer v0.5

This public pre-release adds independent subtitle and audio language control
to the per-item settings foundation. It is an immutable fork point for
contributors who want to extend multilingual playback and track-selection
behavior.

## Highlights

- Stores ordered subtitle and audio language preferences such as `tr,tur,en`
  and `es,spa,en` independently per queue item.
- Provides English, Turkish, and Spanish preference presets while preserving
  inherited, explicit, and mixed multi-edit states.
- Reads and normalizes current-file mpv track metadata without exposing raw
  commands or trusting malformed media metadata.
- Resolves off, explicit ID, ordered language, default, forced, first-track,
  and unavailable cases through one documented deterministic policy.
- Tags post-load track inspection with the playback generation, so a delayed
  track ID from one episode cannot leak into the next.
- Populates subtitle and audio selectors with automatic, off, and current-file
  specific choices and explains unavailable preferences without rewriting
  stored language order.
- Applies subtitle visibility, subtitle delay, and audio delay independently,
  including signed live updates and per-setting reset.

## Requirements and compatibility

- Windows 10 or Windows 11
- Python 3.12 for the development wheel
- PySide6 6.x from the locked runtime requirements asset
- A separate trusted mpv installation; mpv is detected but is not bundled

Install the locked runtime requirements and wheel in a fresh Python 3.12
virtual environment, then run `mpv-enhancer`. Existing v0.4 machine-local mpv
preferences remain compatible. Playlist persistence has not shipped, so no
playlist migration is required.

## Track fallback policy

Off remains off, and a specific ID is used only when it exists for the current
file and track type. Otherwise ordered language tags are checked left to right.
If none match, MPV Enhancer uses the first default track, then a forced
subtitle track, then source order. With no track, subtitles resolve off and
audio remains automatic. A non-blocking explanation identifies fallback use.

## Known limitations

- Settings exist only for the current in-memory queue; playlist save/open and
  session recovery are planned for a later slice.
- Available IDs describe the currently playing file; language preferences are
  the portable per-item choice when IDs differ between files.
- Advanced crop, aspect, zoom, pan, rotation, deinterlace, and image controls
  are not included yet.
- The planned three-second transition experience is not included yet.
- Local files only; folders, remote URLs, and network streams are rejected.
- No standalone executable or installer; this release is a Python wheel plus a
  locked runtime requirements file.
- mpv is an external application and is not included in any release asset.
