# MPV Enhancer v0.3

This public pre-release completes embedded mpv playback and resilient JSON IPC.
It is an immutable fork point for contributors who want to extend the playback
foundation independently.

## Highlights

- Embeds mpv in a stable native Qt video host that remains attached through
  resize, minimize/restore, and full-screen transitions.
- Starts mpv without a command shell, owns only that child process, bounds
  shutdown, and permits one automatic restart after an unexpected exit.
- Uses a random local Windows named pipe with overlapped duplex I/O,
  cancellation, reconnect, UTF-8 line framing, request IDs, and timeouts.
- Loads local files as JSON values, including paths with spaces, Unicode,
  apostrophes, and a leading-hyphen filename.
- Provides Previous, Play/Pause, Stop, Next, absolute seek, duration, progress,
  and `F11` full-screen controls.
- Tags every load with a generation so stale `file-loaded` and `end-file`
  events cannot overwrite or advance the current item.
- Shows path-free English errors with Retry and Stop actions for unplayable
  files and recoverable process or IPC failures.

## Requirements and compatibility

- Windows 10 or Windows 11
- Python 3.12 for the development wheel
- PySide6 6.x from the locked runtime requirements asset
- A separate trusted mpv installation; mpv is detected but is not bundled

Install the locked runtime requirements and playback-enabled wheel in a fresh
Python 3.12 virtual environment, then run `mpv-enhancer`. Existing v0.2 local
preferences remain compatible and no playlist migration is required.

## Known limitations

- Local files only; folders, remote URLs, and network streams are rejected.
- No persisted playlist, per-item playback settings, subtitle controls, volume
  controls, or playback-speed controls yet.
- Hardware and video-output combinations beyond the validated Windows 11 host
  may expose driver-specific `--wid` behavior.
- Recovery is bounded to one automatic child restart; a second process failure
  requires stopping playback and checking Preferences.
- No standalone executable or installer; this release is a Python wheel plus a
  locked runtime requirements file.
- mpv is an external application and is not included in any release asset.
